=================================
  独居单人餐合集 · 在线菜谱 APP
  使用部署说明
=================================

📱 这是什么？
这是一个可以安装在手机桌面上的菜谱应用。
顾客点开就能浏览全部 62 道菜，支持离线查看，
你更新菜谱后顾客打开会自动同步。

━━━━━━━━━━━━━━━━━━━━━━━━━
一、免费部署上线（选一个）
━━━━━━━━━━━━━━━━━━━━━━━━━

方式 A：GitHub Pages（推荐，永久免费）
1. 注册 GitHub 账号：github.com
2. 新建仓库 → 仓库名填 用户名.github.io
3. 把这个 pwa_app 文件夹里的所有文件上传到仓库
4. 进入 Settings → Pages → 选择 main 分支
5. 等 2 分钟，你的菜谱 APP 就上线了
   访问地址：https://用户名.github.io

方式 B：Netlify（更简单，拖拽上传）
1. 打开 netlify.com
2. 用 GitHub 或 Google 登录
3. 把 pwa_app 文件夹直接拖到浏览器窗口里
4. 自动上线，会给你一个 xxx.netlify.app 的地址

━━━━━━━━━━━━━━━━━━━━━━━━━
二、把链接发给顾客
━━━━━━━━━━━━━━━━━━━━━━━━━

上线后你会得到一个网址，类似：
https://你的名字.github.io

把这个链接发给顾客，对方用手机浏览器打开，
点击「安装到桌面」按钮，就会像 APP 一样出现在桌面。

━━━━━━━━━━━━━━━━━━━━━━━━━
三、更新菜谱（实时更新）
━━━━━━━━━━━━━━━━━━━━━━━━━

以后你想加新菜、改内容，流程如下：

1. 告诉我你想改什么（加菜、删菜、改步骤等）
2. 我帮你重新生成 pwa_app 文件夹
3. 你把新文件覆盖到 GitHub / Netlify 上
4. 顾客下次打开 APP 自动获取最新内容
   （不需要重新安装，不需要通知顾客）

━━━━━━━━━━━━━━━━━━━━━━━━━
四、文件说明
━━━━━━━━━━━━━━━━━━━━━━━━━

index.html          - 主页面（全部菜谱）
manifest.json       - APP 配置（安装信息）
service-worker.js   - 离线缓存（自动更新）
icon-192.png        - 桌面图标（小）
icon-512.png        - 桌面图标（大）
version.json        - 版本号（用于检查更新）
使用说明.txt        - 本文件
